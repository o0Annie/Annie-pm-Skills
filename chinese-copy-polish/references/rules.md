## 1. 结论先行

中文读者习惯「先给结果，再给过程」。段落和小节开头第一句就点明价值或结论。

- 病例：为了帮助你更好地保护自己的肖像，平台提供了一套完整的实名与授权流程，完成之后你将获得一张证书。
- 改写：完成实名与授权，你就能拿到一张肖像保护证书。

## 2. 拆长句、去名词堆砌

一句一个意思。40 字以上先想能不能拆。把「……的……的……」名词链改成动词句。

- 病例：用户可通过在个人中心页面对收款账户信息进行绑定操作以完成后续的提现功能使用。
- 改写：在个人中心绑定收款账户，就能提现。

- 病例：平台支持对演员素材的多维度标签化分类管理能力。
- 改写：平台会给演员素材打上多种标签，方便分类和查找。

## 3. 去翻译腔（含词表）

删虚词套路、被动改主动。常见翻译腔 → 改法：

- 「进行 X」→ 直接用动词（进行审核 → 审核）
- 「对 X 进行 Y」→ 「Y X」（对素材进行预览 → 预览素材）
- 「基于 / 通过……的方式」→ 删掉或改「用」
- 「实现了 X 功能 / 能力」→ 「能 X」
- 「拥有 / 具备 X」→ 「有 X」
- 「被 X」被动 → 主动（每次被使用 → 每次有人用 / 每次使用）
- 「众所周知 / 值得注意的是 / 需要指出的是」→ 删
- 「该 / 此 X」书面代词 → 「这个 X」或直接省略
- 「以及 / 及」堆叠 → 用顿号或拆句

- 病例：该功能可实现对用户提交的素材进行合规性审核的能力。
- 改写：这个功能用来审核用户提交的素材是否合规。

## 4. 克制装饰（加粗 / emoji / 破折号）

- **加粗**：一段里最多 1–2 个真正的关键词。整句加粗、每句都加粗 = 没有重点。
- **emoji**：每个小节标题最多一个；正文尽量不用。删掉纯装饰性的 ✨🎉🚀 堆叠。
- **破折号 `——`**：不要用它串接半句。中文里改用句号断句，或用冒号引出。
  - 病例：元相新生是你的数字肖像管家——它既保护你的脸，也让你的脸赚钱——一切由你决定。
  - 改写：元相新生是你的数字肖像管家：既保护你的脸，也让你的脸赚钱，一切由你决定。

## 5. 说人话（黑话对照表）

产品/运营黑话 → 人话：

- 赋能 → 帮助 / 让……能
- 抓手 / 抓住心智 → 删（换成具体动作）
- 场景化 / 场景 → 直接说用途（「场景化用法」→「怎么用」「主要功能」）
- 闭环 → 完整流程 / 走通
- 沉淀 → 积累 / 保存
- 对齐 → 说清 / 统一
- 颗粒度 → 细到什么程度
- 心智 → 印象 / 认知
- 链路 → 流程 / 环节

## 6. 排版规范（间距 / 标点）

- 中文与英文、中文与数字之间加空格：使用 App、3 个工作日、AI 试镜。
- 数字 + 单位若是中文习惯量词，可不加空格：3 天、5 元、2 步（视风格统一即可）。
- 中文语境统一用全角标点：，。：；？！「」（）。不要在中文句里用半角 , . : ; ?。
- 括号：中文内容用全角（），纯英文/代码用半角。
- 省略号用「……」不用「...」；书名/作品用《》。

## 7. 手册/指南场景专项

- **面向读者用「你」**：用户手册用第二人称「你」，比「用户可以」更亲切自然。
- **步骤用祈使句**：「打开 App，输入手机号」优于「用户需要打开应用程序并输入其手机号码」。
- **一步一动作**：编号步骤里一条只放一个动作，别把三件事塞一句。
- **标题即目标**：How-to 小节标题用「做什么」命名（「查看收益并提现」），不用「XX 功能介绍」。
- **标题只用名词/目标短语，不塞旁白**：章节标题不放口语解释、教学旁白或括号补充说明，解释放到标题下面的正文。市面惯例（中文 SaaS 与英文文档一致）是干净名词短语：快速上手 / 快速入门 / 新手指南 / Quick Start / Getting Started。
  - 病例：`## 🚀 新手上路（第一次使用，跟着走一遍）`
  - 改写：`## 🚀 快速上手` ，下一行正文再写「第一次使用，跟着下面几步走一遍……」
  - 例外：括号里是**限定范围**而非旁白时可保留，如「制作方端使用指南（电脑端 + 手机端）」「用户使用指南（手机端）」。判断标准：括号内是「适用范围/端/版本」→ 保留；是「怎么读、给谁看、鼓励的话」→ 删掉下沉到正文。
- **Q&A 简短**：一问一答，答句先给结论再补条件。
- **场景视角开头（先目的、后步骤）**：每个操作小节用「如果你想…」开头，先让读者确认「这是不是我要找的功能」，再给步骤，最后补说明。中国读者习惯先看目的再看操作。
  - 病例：完成前三步就行。
  - 改写：**如果你只想保护肖像、暂时不接单：** 完成【快速上手】前 3 步即可。
- **陪伴式语气（不冷、不俚）**：
  - 去生硬：少用「依次点击」「按提示走完即可」这类冷命令，换成「进入」「顺着完成」「点击」。
  - 去俚语：把过于随意的口语换成有温度又规范的词（「片子」→「作品」，「走完这步就行」→「完成前 3 步即可」）。
  - 加温度：在容易焦虑的节点加一句关怀（「没通过会告诉你原因」→「不用担心，系统会提示具体原因」）。
- **路径与平行可视化**：连续点击用 ➔（【我的】➔【设置】➔「注销账号」）；平行功能逐条列成无序列表，别挤在一句里。
- **提示分离（callout）**：注意事项、核心权益、关键规则用 `> 💡` 引述块单独框出，不混进主流程正文。
- **拆分交织逻辑**：一段里混了多套逻辑时（如试镜机制 + 分成 + 付费），拆成平行分支，并把关键规则用括号或 callout 单独标注（「试镜不分成，签约才拿钱」）。
- **分支流程拆成带小标题的两段**：当步骤里有「可选进阶」分叉时，别在步骤标题塞条件旁白（如「（想接单再往下）上传素材」），改成两段带小标题的清单，中间用 `> 💡` callout 分界。
  - 病例：`4. （想接单再往下）上传素材：…`
  - 改写：拆成 `**第一段 · 保护你的脸**`（1–3 步）与 `**第二段 · 成为数字演员**`（1–3 步），中间加 `> 💡 只想保护，到这就够了；想接单赚钱，继续第二段。`

## 8. 改写自检清单

改完逐条过一遍：

- [ ] 每节 / 每段第一句是否点明重点？
- [ ] 有没有超过 40 字还不断句的长句？
- [ ] 「进行 / 对……进行 / 基于 / 实现了……能力」等翻译腔是否清干净？
- [ ] 加粗是否只留了关键词？emoji 是否每节 ≤ 1？破折号串句是否改掉？
- [ ] 有没有残留黑话（赋能 / 场景化 / 抓手 / 闭环 / 心智）？
- [ ] 中英文 / 中数之间空格、全角标点是否规范？
- [ ] 章节标题是否为干净的名词/目标短语，没塞口语旁白或括号解释（限定范围的括号除外）？
- [ ] 每个操作小节是否「先目的（如果你想…）、后步骤」？
- [ ] 有没有「依次点击 / 按提示走完即可」这类冷命令，或「片子」这类俚语？焦虑节点是否加了一句关怀？
- [ ] 连续点击是否用 ➔？平行功能是否逐条列？提示 / 权益是否用 `> 💡` 引述块分离？
- [ ] 事实（数字 / 流程 / 功能）是否与原文完全一致，没被改动或新增？
