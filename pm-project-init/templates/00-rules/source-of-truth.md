# 唯一事实源

核心原则：每类信息只有一个维护位置，其他地方只引用不复制。

| 信息 | 唯一维护位置 |
| --- | --- |
| 原始输入登记 | `01-inputs/source-register.md` |
| 产品术语与背景 | `02-product/` |
| 跨需求决策 | `03-planning/` |
| 需求状态、优先级、负责人 | `04-requirement-pool/requirement-pool.md` |
| 单需求定义、原型、PRD | `05-requirements/req-XXXX-*/` |
| 版本承诺范围 | `06-versions/<version>/scope.md` |
| 评审、验收、复盘结论 | `07-reviews/` |

发现同一信息在两处不一致时，以上表位置为准，并修正引用方。
